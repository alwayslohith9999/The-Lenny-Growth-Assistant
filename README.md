# Lenny Growth Assistant

An internal tool that allows product and growth teams to ask questions grounded in Lenny's Podcast transcripts, generate Ship 30 for 30-style essays from those insights, and render Markdown/HTML artifacts inline next to the chat interface.

## Repository Structure

- `/backend` - FastAPI backend application
- `/frontend` - React (Vite) frontend application
- `/ingestion` - Transcript ingestion, chunking, and embedding scripts
- `/docs` - PRD, Architecture, and Design documentation
- `/agent-transcripts` - Development agent transcripts and execution logs
- `/tests` - Backend unit and integration test suites

Refer to `docs/PRD.md` and `docs/architecture.md` for project details.
